## Ограничения и восстановление

PDF создаётся через печать браузера, отдельного серверного PDF-конвертера нет.
Электронная подпись, новый процесс согласования и интеграции SIEM в этот этап не входят.

Для отката сначала сохранить свежий дамп и файловые тома. Не выполнять
`alembic downgrade` без сохранения карточек: эта операция удаляет новую таблицу.
Возврат прежнего кода без удаления таблицы сохраняет данные карточек в БД,
но прежний интерфейс их не показывает. Восстановление БД из дампа поверх
существующей базы требует отдельного решения с учётом новых записей после обновления.
