# Перенос полного графа расследования beta.23

Пользователь подтвердил полный перенос графа 18 ноября 2026 года.
Целевая ветка — `codex/dfir-iris-beta-features`.

## Исходники

- Backend tag `v3.0.0-beta.23`, commit `e58e450c9a9f2d3aa3064d524e8999fd43aed04d`.
- Frontend tag `v3.0.0-beta.23`, commit `3e02ba0d221235968b188c440faaeac4169f0714`.
- Контракт — `dfir-iris/iris-web`, `docs/investigation-graph.md` на том же теге.
- Локальные справочные checkout находятся в `.venv/upstream-graph-backend-beta23` и
  `.venv/upstream-graph-frontend-beta23`.

Полноту проверять по реализации тега и контракту вместе. Документ upstream содержит
проектные требования и расширения, поэтому одна ссылка на документ не подтверждает
наличие функции в конкретной сборке.

## Порядок интеграции

1. Модель и миграции `case_graph`, каталог отношений, схема API. Перенести сохранённые
   `investigation_graph_*` записи и ключи представлений без потери идентификаторов,
   событий-подтверждений и расположения узлов. Проверить обновление существующей базы.
2. Сборка графа с активами, IOC, событиями, файлами, задачами, заметками, алертами и
   переходами между кейсами. Перенести признаки компрометации, метки, TLP,
   обогащение и время наблюдения. Проверить разграничение доступа.
3. Полное создание и редактирование связей и свободных узлов. Обратное направление,
   рецензирование, преобразование узлов, вставка IOC, очистка связей при удалении
   объектов, объединение производных и сохранённых связей.
4. Исследование графа. Окрестности, направленные пути, ограничения запросов,
   обработка отсутствующих узлов.
5. Cytoscape и компоненты графа из upstream. Добавить зависимости и адаптировать
   существующие сервисы, контексты и локализацию. Подключить раскладки, перетаскивание
   связей, поиск, таблицы, клавиатуру, undo/redo, временные фильтры и карту обзора.
6. Представления с владельцами, общим доступом, снимками и выбором для отчёта.
   Экспорт PNG/SVG, JSON/STIX/GraphML и импорт JSON/STIX.
7. Подсказки, пробелы расследования, AI-предложения и объяснение через действующий
   провайдер Yuki. Сохранить его ограничения доступа, аудит и лимиты.
8. Обновления Socket.IO, присутствие, журнал действий, хуки, MCP, отчёты,
   перенос кейсов и граф War Room с проверкой доступа к каждому кейсу.
9. Проверка сценариев в Chrome с PostgreSQL, миграций и регрессий существующих
   графов алертов и кластеров. Затем итоговый аудит по каждому пункту.

## Подтверждённое состояние рабочей копии

- Подключён просмотр графа в таблицах узлов и связей с фильтрацией,
  сортировкой, разбивкой на страницы и открытием карточки из строки.
  При переключении Cytoscape сохраняет текущий вид. Проверка клавиатурного
  сценария в Chrome остаётся открытой. Добавлен групповой выбор строк
  и переход к их положению на графе с подсветкой. Групповое редактирование
  и экспорт выделения ещё требуют переноса.

- Перенесены пять правил обнаружения пробелов расследования beta.23.
  Панель получает результаты через API кейса и подсвечивает выбранные
  узлы и связи. Тест алгоритма проверяет все пять правил. Сквозная
  проверка панели в Chrome остаётся открытой.

- Подключён импорт JSON и STIX. API требует полного доступа к кейсу,
  повторно использует существующие узлы и IOC, пропускает дубликаты связей,
  сохраняет весь импорт в одной транзакции. Форма показывает число добавленных
  и пропущенных элементов. Проверены разбор обратной выгрузки STIX и пропуск
  производных связей JSON. На FastAPI/PostgreSQL проверены повторный импорт без
  дубликатов, перенос экспортированного STIX во второй кейс и отклонение
  некорректного JSON. В Chrome проверена загрузка файла и счётчик новых узлов.

- Подключён экспорт JSON, STIX 2.1 и GraphML через API с проверкой доступа
  к кейсу. В интерфейсе также добавлена выгрузка PNG и SVG из Cytoscape.
  Тесты сериализации проверяют типы и направление связей, ссылки STIX
  и экранирование XML. В Chrome скачаны все пять форматов, проверены
  имена и содержимое файлов.

- В Cytoscape подключена панель поиска путей. Она передаёт в API
  конечные узлы, направление и включённые типы объектов. Выбранный путь
  подсвечивается на графе, остальные элементы приглушаются.
  В Chrome проверен поиск направленного пути через API и отображение результата.

- Файлы доказательств, задачи и заметки доступны как узлы графа через
  `include=evidences,tasks,notes`. Хранилище проверяет принадлежность объектов
  кейсу при чтении и записи связей и загружает конечные узлы сохранённых
  связей независимо от фильтра. В интерфейсе подключены фильтры и переходы
  к карточкам, настройки включения сохраняются в представлении.
  Этот сценарий ещё требует сквозной проверки.

- Страница графа кейса использует компонент Cytoscape из beta.23.
  В Chrome с FastAPI/PostgreSQL проверены шесть раскладок, восстановление
  координат и масштаба старого представления, клик по ребру и редактирование
  типа связи с сохранением после перезагрузки. Прошли 49 тестов Cytoscape.
  Остальные интерфейсы графа beta.23 ещё в работе.

- Модель `case_graph.py` перенесена из закреплённого backend beta.23.
  Миграция `utmn_case_graph01` создаёт новую схему и 15 системных типов отношений.
  Проверены на отдельной PostgreSQL 18 создание, повторное применение, откат,
  повторное создание, совпадение колонок с ORM и сохранность прежних данных.
  Код хранения ручных объектов подключён к новой схеме с прежним форматом API.
  Миграция копирует существующие узлы, связи, подтверждающие события и представления,
  сохраняет ID и сбрасывает последовательности выше перенесённых записей.
  На PostgreSQL проверены перенос расположений, создание следующего узла,
  изменение типа связи с сохранением подтверждений, ограничение по case_id
  и удаление связей удаляемого узла. После переключения HTTP-сценарий
  FastAPI/PostgreSQL подтвердил создание и чтение узлов и ручных связей,
  включая пользовательские типы, удаление и поиск пути.
- Подключён каталог отношений beta.23 через `/manage/graph-relation-types`.
  Администратор может создавать, изменять, удалять и переупорядочивать типы.
  Проверены запрет переименования системного типа, подсчёт использующих связей,
  запрет удаления используемого типа, удаление после освобождения, создание
  связи пользовательского типа. Форма графа читает каталог из базы.
  Экран `/settings/graph-relations` перенесён и подключён к меню администратора.
  В Chrome с FastAPI/PostgreSQL проверены создание, цвет, штриховая линия,
  редактирование, сохранение после перезагрузки, перемещение в списке и удаление.
  Проверены русские подписи экрана и диалога. Прошли 13 тестов формы и прав
  настроек, проверка Svelte завершилась без ошибок. Выбор пользовательского
  типа непосредственно в форме связи графа ещё требует браузерной проверки.
- Базовый граф, ручные узлы и связи, роли событий и простые представления существуют.
- Узлы событий и родительские связи проверены через API и Chrome с PostgreSQL.
- Производные типы отношений и отдельные подтверждения параллельных связей проверены
  через API и Chrome с PostgreSQL.
- Добавлены необязательные типы ручных связей. Создание через форму и сохранение
  после перезагрузки проверены. Обновление через API, отклонение неизвестного типа
  и совместимость прежнего payload проверены. Редактирование через форму ещё
  требует проверки.
- Штатные PNG упакованы в v3. Раздача и преобразование для тёмной темы проверены
  через ASGI, SvelteKit и Chrome.
- Добавлен доступный с клавиатуры список выбора связи. Проверка типов прошла,
  браузерный сценарий остаётся открытым.
- Алгоритмы исследования окрестностей и путей перенесены из backend beta.23.
  Подключены маршруты к текущей сборке графа с проверкой доступа к кейсу.
  Проверены направление, циклы, изолированные узлы, несуществующие узлы и
  недопустимая глубина. Сквозная проверка маршрутов остаётся открытой.

Полный перенос остаётся в работе. Наличие базового графа не закрывает перечисленные
этапы и не подтверждает готовность полного функционала beta.23.
