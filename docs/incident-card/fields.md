# Поля карточки и источники

Основная форма: приложение 4, страницы 28–31. Дополнительные технические поля взяты из предоставленных скриншотов. Ручная правка отключает синхронизацию конкретного поля.

## Общие сведения

| Поле | Ключ API | Источник |
|---|---|---|
| Идентификатор | id | cases.case_id |
| Название инцидента | title | cases.name |
| Дата и время инцидента | incident_at | selected alert: alert_source_event_time |
| Источник обнаружения | detection_source | selected alert: alert_source |
| Внешний идентификатор | external_id | selected alert: alert_source_ref |
| Критичность | criticality | cases.severity |

| Время реакции | reaction_seconds | Обнаружение → начало расследования |
