# Glassmorphism Modern UI Theme для DFIR-IRIS

## Обзор

Glassmorphism Modern UI - это футуристичная тема с эффектом матового стекла, глубокими тенями и анимированными градиентами. Тема оптимизирована для темного режима и создает современный, профессиональный интерфейс для DFIR-IRIS.

## Особенности

### Визуальные эффекты
- **Glassmorphism карточки** - полупрозрачные карточки с размытием фона (backdrop-filter blur)
- **Анимированный фон** - плавающие градиентные пятна на заднем плане
- **Светящиеся акценты** - критические алерты пульсируют красным свечением
- **Глубина и объем** - многослойные тени для создания 3D эффекта
- **Плавные анимации** - hover эффекты и переходы с cubic-bezier

### Статусы и бейджи
Все статусы алертов имеют уникальные градиенты:
- **New** - синий градиент с голубым свечением
- **Open** - оранжевый градиент
- **Closed** - зеленый градиент
- **Resolved** - фиолетовый градиент
- **Pending** - розовый градиент
- **Critical** - красный градиент с пульсирующей анимацией

### Компоненты

#### Карточки алертов
```css
.card.status-new { /* Синее свечение */ }
.card.status-critical { /* Красное пульсирующее свечение */ }
```

#### Кнопки
- Primary - синий градиент с hover эффектом подъема
- Secondary - полупрозрачный с glassmorphism эффектом
- Danger - красный градиент для опасных действий

#### Теги и IOC badges
- Полупрозрачные с размытием фона
- Hover эффект с подъемом
- Уникальные цвета для разных типов IOC (IP, Domain, Hash)

#### Навигация
- Glassmorphism sidebar и navbar
- Активные элементы подсвечены градиентом
- Плавные hover переходы

## Установка

### Автоматическая (уже выполнено)

1. CSS файл создан: `source/app/static/assets/css/glassmorphism-theme.css`
2. Интегрирован в шаблон: `source/app/templates/layouts/default.html`
3. Активируется автоматически при включении темной темы

### Включение темы

Пользователи включают тему через профиль:
1. Зайти в настройки профиля
2. Включить **Dark Mode**
3. Glassmorphism тема загрузится автоматически

### Ручная установка (если нужно)

```bash
# Убедитесь что файл существует
ls source/app/static/assets/css/glassmorphism-theme.css

# Проверить что подключен в шаблоне
grep glassmorphism source/app/templates/layouts/default.html
```

## Совместимость

### Браузеры
- ✅ Chrome 76+
- ✅ Firefox 103+
- ✅ Safari 9+ (с -webkit- префиксами)
- ✅ Edge 79+
- ⚠️ Старые браузеры - фоллбэк на обычный dark theme

### Особенности
- `backdrop-filter` может требовать производительность GPU
- На слабых машинах можно отключить анимации
- Поддержка `prefers-reduced-motion` для доступности

## Настройка

### Изменение цветов

Откройте `glassmorphism-theme.css` и измените CSS переменные:

```css
:root {
  --glass-bg: rgba(255, 255, 255, 0.08);  /* Прозрачность стекла */
  --glass-border: rgba(255, 255, 255, 0.12);  /* Граница стекла */
  --accent-blue-glow: 0 0 20px rgba(59, 130, 246, 0.5);  /* Свечение */
}
```

### Отключение анимаций

Для производительности или доступности:

```css
/* Браузер автоматически применит если пользователь настроил */
@media (prefers-reduced-motion: reduce) {
  /* Анимации отключены */
}

/* Или вручную добавьте в пользовательский CSS */
.main-panel::before {
  animation: none !important;
}
```

### Кастомизация силы свечения

```css
/* Увеличить свечение для критических алертов */
.card.status-critical {
  box-shadow: 0 0 50px rgba(239, 68, 68, 0.9) inset !important;
}
```

## Сравнение с другими темами

| Характеристика | Dark Theme | Modern UI | Glassmorphism |
|----------------|------------|-----------|---------------|
| Прозрачность | Нет | Частично | Да (полная) |
| Размытие фона | Нет | Нет | Да |
| Анимации | Минимальные | Некоторые | Богатые |
| Производительность | Высокая | Высокая | Средняя |
| Визуальный эффект | Стандартный | Современный | Футуристичный |

## Известные ограничения

1. **Производительность** - backdrop-filter может замедлять старые GPU
2. **Сложность** - больше CSS кода чем в базовой теме
3. **Читаемость** - некоторые пользователи могут предпочесть более высокий контраст

## Поддержка

При проблемах:
1. Проверьте что темная тема включена
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте консоль браузера на ошибки CSS
4. Убедитесь что браузер поддерживает backdrop-filter
