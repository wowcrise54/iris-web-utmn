## Variant: Utilitarian Dense

### Design stance
Maximum information density for power users who need to process many alerts quickly.

### Key choices
- **Layout**: Compact grid, minimal whitespace, data-dense tables
- **Typography**: Small but readable, monospace for IOCs, uppercase labels
- **Color**: High contrast dark theme, bright status indicators
- **Interaction**: Quick hover feedback, minimal animations for performance
- **Shadows**: None - flat design for maximum clarity

### Trade-offs
- **Strong at**: Information density, quick scanning, low-light operations
- **Weak at**: Long-term viewing comfort, accessibility for visually impaired

### Best for
- SOC analysts processing high volumes of alerts
- Night shift operations
- Power users who know the interface well
- Environments where speed is critical

### Comparison
- Most dense of all variants
- Best for experienced users
- Steepest learning curve for new users
