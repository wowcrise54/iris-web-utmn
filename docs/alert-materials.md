# Материалы анализа оповещения

В карточке оповещения и разделённом представлении очереди аналитик может
добавлять IOC и отвязывать их от оповещения. Сам IOC и связи с другими
оповещениями и кейсами сохраняются. Редактирование IOC, уже находящегося
в кейсе, дополнительно требует полного доступа к этому кейсу.

Раздел «Артефакты» поддерживает файлы до 200 MiB и текстовые записи:
процесс, команда, путь, ключ реестра, другое. Для материалов сохраняются
автор, время создания, описание, история действий; для файлов — размер
и SHA-256. Загрузка и скачивание не запускают содержимое файла.

Управление доступно только текущему ответственному с `alerts_write`.
У неназначенного оповещения редактора материалов нет. Проверки действуют
на сервере независимо от видимости кнопок. Чтение требует доступа к
оповещению и `alerts_read`.

Флаг «Копировать в кейс при эскалации» выбирает артефакты для переноса.
При эскалации или объединении они копируются в файловое хранилище кейса;
текстовые записи сохраняются как `.txt`. Требуется полный доступ к кейсу.
Копии независимы от исходных материалов. Повторный перенос той же записи
в тот же кейс не создаёт копию повторно.

API: `/api/v2/alerts/{alert_id}/iocs` (POST),
`/iocs/{ioc_id}` (PUT, DELETE), `/artifacts` (GET, POST),
`/artifacts/{id}` (PUT, DELETE), `/artifacts/{id}/content` (GET).
POST артефакта принимает JSON либо multipart с полем `file`.

Новая миграция: `utmn_alert_materials01` после `utmn_incident_card01`.
Файлы хранятся в `DATASTORE_PATH/alerts/{alert_id}` с серверными UUID.
Для резервного копирования нужны PostgreSQL и том server-data.

Проверка 15 октября 2026: 51 backend unit-тест, 9 тестов валидации,
42 frontend-теста; svelte-check — 0 ошибок, 9 существовавших предупреждений.
Функциональный тест локального API проверяет IOC, двоичный файл/хеш,
права неназначенного alert, выбранный перенос и независимость копии кейса.
Тестовые alert и кейс удаляются после проверки.
