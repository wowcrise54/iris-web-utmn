# PT Sandbox 5.39 MCP в IRIS

IRIS получает сводки существующих заданий через штатный MCP-сервер PT Sandbox.
Новые проверки запускаются в PT Sandbox.

## Подключение

1. В PT Sandbox выпустите токен с разрешением **Чтение данных через MCP-сервер**.
   Это разрешение даёт доступ к данным всех заданий на выбранном сервере.
2. В IRIS откройте **Настройки → Модули → PT Sandbox**. Укажите HTTPS-адрес
   основного узла с путём `/mcp`, токен и базу `scans_v2` либо `scans_v2_repl`.
   Для внутреннего центра сертификации можно указать путь к доверенному PEM-файлу.
3. Сохраните настройки, нажмите **Проверить подключение** и включите модуль.
   Проверка согласует версию протокола MCP и проверяет доступ к инструменту
   `run_query` и полям сводки в выбранной базе.

При обновлении с REST-версии модуль выключается, прежний адрес и токен удаляются
из конфигурации модуля. Для подключения нужны адрес MCP и токен с новым правом.
Сохранённые сводки, прежние отчёты и скачанные логи доступны в своих инцидентах.
Незавершённые REST-задания помечаются как прерванные. Если IRIS ожидал ответ
на создание задания, он сохраняет статус неопределённой отправки.

## Привязка задания

На вкладке **PT Sandbox** инцидента введите UUID задания (`scan_id`) и его точное
время старта в UTC, например `2026-11-19T10:21:18Z`. Нажмите **Получить результат**.
Для импорта нужен полный доступ к инциденту. Пользователи с доступом на чтение
видят результаты, уже сохранённые в этом инциденте.

Карточка показывает состояние задания, вердикт и приоритет. Сводку можно
скачать в JSON. Пока `verdict_is_final` равен нулю, результат помечен как
предварительный. Для обновления повторите импорт с тем же UUID и временем.
Повторный импорт обновляет существующую запись в инциденте.

Первый этап импортирует сводку задания. Новые записи содержат поля задания
из MCP, включая имя объекта при его наличии. Исходные бинарные логи, хеши
из дерева объектов и автоматические уведомления war room в этот этап не входят.
Ранее скачанные логи доступны для просмотра и анализа Yuki по существующему
сценарию.
