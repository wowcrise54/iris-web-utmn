# PT Sandbox 5.39 MCP в IRIS

IRIS получает сводки существующих заданий через штатный MCP-сервер PT Sandbox.
Новые проверки запускаются в PT Sandbox.

## Подключение

1. В PT Sandbox выпустите токен с разрешением **Чтение данных через MCP-сервер**.
   Это разрешение даёт доступ к данным всех заданий на выбранном сервере.
2. В IRIS откройте **Настройки → Модули → PT Sandbox**. Укажите HTTPS-адрес
   основного узла с путём `/mcp`, токен и базу `scans_v2` либо `scans_v2_repl`.
   Для внутреннего центра сертификации можно указать путь к доверенному PEM-файлу.
3. Сохраните настройки, нажмите **Проверить подключение** и включите модуль.
   Проверка согласует версию протокола MCP и проверяет доступ к инструменту
   `run_query` и полям сводки в выбранной базе.

При обновлении с REST-версии модуль выключается, прежний адрес и токен удаляются
из конфигурации модуля. Для подключения нужны адрес MCP и токен с новым правом.
Из прежних вложений в инцидентах доступны сохранённые сетевые захваты PCAP и PCAPNG.
Незавершённые REST-задания помечаются как прерванные. Если IRIS ожидал ответ
на создание задания, он сохраняет статус неопределённой отправки.

## Привязка задания

На вкладке **PT Sandbox** инцидента введите имя файла или его часть и выберите
период поиска. Поиск учитывает последние 30 дней по умолчанию и возвращает до
30 новых совпадений. Чтобы выбрать нужную проверку одноимённого файла, сравните
время старта, статус и вердикт. UUID и точное время в UTC можно указать вручную.

Для поиска и импорта нужен полный доступ к инциденту. Поиск обращается к базе,
доступной общему токену модуля. Пользователи с доступом на чтение видят только
результаты, уже сохранённые в данном инциденте.

При привязке IRIS сначала получает количество событий по типам, затем загружает
до 1000 событий в хронологическом порядке. Сырые пакеты `netpacket` исключаются.
Карточка показывает охват выборки. Если ответ превышает предел размера, IRIS
загружает события меньшими страницами до достижения общего лимита. Кнопка **Обновить события** обновляет
существующую запись без дубликатов.

Нажмите **Проанализировать события с Yuki**, чтобы открыть чат инцидента с
готовым запросом по выбранной проверке. Через `iris_case_sandbox_events_get`
Yuki получает распределение событий и запрашивает нужные типы небольшими
порциями. В чате можно задавать уточняющие вопросы. Сводка охвата указывает,
если загружена только часть событий.

Сохранённые PCAP и PCAPNG можно скачать или открыть в локальном анализе PCAP.
Для нового задания скачайте захват в интерфейсе PT Sandbox и приложите его к
инциденту IRIS. Штатный MCP предоставляет SQL-доступ к событиям и не предоставляет
операцию скачивания бинарного захвата.
